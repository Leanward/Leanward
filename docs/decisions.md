| 2026-11-02 | **Alcohol tracking** (LOG-14, P1) as a Profile toggle, with standard drinks, alcohol calories and a user-set daily limit (DGA default). | 2026-11-02 | Lab history is **append-only**: each import or hand entry adds a report; nothing is replaced, and reports are deleted only individually by the user. Each marker gets a **Between reports** view (marker change, linked-nutrient intake, weight change, phase per period). | Owner wants to trend results over time and see whether diet may have played a part. | 2026-11-02 | When a lab report has no printed range, **eGFR uses the standard < 60 mL/min/1.73m² cutoff**; every other marker stays unflagged. | Owner (clinician) decision: eGFR < 60 is a near-universal threshold (KDIGO), and the protein-safety rule (LAB-7) shouldn't depend on a range being typed in. Creatinine has no single standard range. |
| 2026-11-02 | Labs are **lab-neutral**: the action is "Import labs" (any lab's PDF) with **optional manual entry**; no lab company is named in the product. Hand-entered results use the range the user types from their report, or are shown unflagged. | Most users won't use Function Health. Keeping both paths from the start lets people without a readable PDF still use Labs, without Leanward inventing reference ranges. |
